# Security and Responsible Research

This repository contains educational experiments. Do not submit confidential system data, credentials, private symbols, or production artifacts.

## Reporting
If you identify a security issue in a third-party product while performing an authorized exercise, follow that vendor's published vulnerability disclosure process. Do not open a public issue containing an unpatched vulnerability, exploit chain, personal data, or sensitive evidence.

## Scope
Only test systems you own or are explicitly authorized to assess. Use isolated virtual machines and snapshots for experiments that may affect system stability.
